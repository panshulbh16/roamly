# Destination catalogue

`cities.json` and `countries.json` are generated from the GeoNames `cities500` and `countryInfo` exports by `scripts/import-destinations.py`.

GeoNames data is licensed under [CC BY 4.0](https://www.geonames.org/export/). The local catalogue contains cities and towns with a population of at least 500, plus countries and territories. Continents are maintained in the application source.

`name-index.json` is generated by the same importer from GeoNames' alternate-name field, retaining historical names, transliterations and local scripts. Re-running the import refreshes names without city-specific code changes. Short ASCII alternate codes (three characters or fewer) and numeric-only names are excluded; canonical names remain searchable. This catalogue does not cover every small village or guarantee every historical spelling.

The index is sorted by UTF-16 name order for binary lookup in JavaScript. Entries contain normalized names and population-ordered positions in `cities.json`. Exact matches are validated; fuzzy matches are suggestions only. Country/region qualifiers distinguish places sharing a name. Unqualified matches default to the most populous candidate, preferring a canonical name within that country.

Refresh all three source dumps together from https://download.geonames.org/export/dump/ and run:

```sh
python3 scripts/import-destinations.py cities500.zip countryInfo.txt admin1CodesASCII.txt
node --test tests/destinations.test.mjs
```
